# Сборка и проверка сайта

## Готовые файлы

`node scripts/build-domain.mjs` создаёт статическую версию для основного домена в `outputs/alexblagov.ru/`.
На сервере для этой версии не требуются Node.js или база данных.

`npm run build:pages` создаёт отдельную GitHub Pages-версию в `out/`.
Эти режимы задают разные базовые пути ресурсов и адреса метаданных.

Workflow `Prepare REG.RU release` создаёт ZIP-артефакт `alexblagov-reg-ru`.
Workflow публикации GitHub Pages также создаёт [публичный пакет готового сайта](https://daridarom.github.io/alexblagov/alexblagov-reg-ru.zip).
В архиве находится отдельная папка выпуска, имя которой содержит SHA коммита.
Пакет содержит только готовые публичные файлы сайта.

## Что проверено

- Сборка, TypeScript и lint.
- Chrome при ширинах 320, 390, 768 px и на компьютере.
- Увеличение корневого шрифта до 200%, включая длинные подписи.
- Меню, раскрывающиеся описания, клавиатурное управление и возврат с ошибочного адреса.
- Все 26 внутренних якорей и локальные ресурсы статической сборки.
- Canonical, Open Graph, robots.txt, sitemap.xml и русская страница 404.
- Новая карточка ссылки: JPEG 1200 × 630, около 78 КБ; читаемость проверена при уменьшении до 320 px.
- Публикация карточки с портретом разрешена пользователем 9 сентября 2026 года.

Проверка в реальных Safari/Firefox и во всех мессенджерах не проводилась.
После размещения нужно проверить фактическое поведение HTTPS, ресурсов, страницы 404 и карточки ссылки.

## Подготовка размещения

Перед заменой действующего сайта необходимо сохранить его индексную страницу и правила веб-сервера, проверить целостность архива и подготовить способ возврата.
Рабочие данные и настройки конкретного переноса ведутся отдельно.
Параметры панели уточняются по [официальной документации ispmanager](https://www.ispmanager.ru/docs/ispmanager/rabota-s-saytom).

## Дальнейшее содержательное усиление

Для описаний конкретных программ полезны подтверждённые даты, длительность, стоимость и примеры результатов участников.
Эти сведения нельзя заменять выдуманными тарифами, отзывами или обещаниями результата.
