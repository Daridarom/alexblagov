# Александр Благов — личный сайт

Новая рабочая версия персонального сайта Александра Благова: предпринимательство и девелопмент в Крыму, TOP THAI SPA, проект «Жизнь без страха», спорт, книга и публичные выступления.

## Локальный запуск

```bash
npm install
npm run dev
```

Проверка перед публикацией:

```bash
npm run lint
npm run build
```

Рабочая версия для согласования: https://alex-blagov-preview.semenovspb.chatgpt.site

Основной домен `alexblagov.ru` на этапе согласования не изменяется.
