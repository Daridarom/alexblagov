# Александр Благов — личный сайт

Исходный код актуальной версии персонального сайта Александра Благова.

Основной публичный домен: `https://alexblagov.ru/`.
GitHub Pages используется как техническое превью и резервная статическая сборка.

## Локальный запуск

```bash
npm ci
npm run dev
```

## Проверка

```bash
npm test
```

Команда выполняет lint, собирает статическую GitHub Pages-версию и проверяет ключевые метаданные итогового HTML.

## Сборка для основного домена

```bash
npm run build:domain
```

Готовые файлы появляются в `outputs/alexblagov.ru/`. На основном хостинге публикуется только эта статическая сборка; исходный репозиторий, Node.js и база данных для работы сайта не требуются.

Подробности процесса выпуска — в `docs/domain-launch.md`.
